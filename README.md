# Kubico — propuesta de rediseño

Preview de revisión preparado por Archilogic a partir del proyecto de Stitch “Rediseño Web Kubico”, pantalla favorita “Modo Día & Noche”.

## Funciones
- Diseño adaptable y menú móvil.
- Modo automático, día y noche con preferencia local.
- Filtros de portafolio.
- Estimador interactivo de superficie, sistema y tiempo ilustrativo.
- Formulario de demostración que no transmite ni almacena datos.

Imágenes, textos comerciales, recintos, calendario, contactos y tiempos proceden de la propuesta y requieren validación por Kubico. No constituye una cotización ni un sistema de disponibilidad real. La autorización del cliente se recaba fuera de este preview.

## Publicación
GitHub Pages: rama `main`, carpeta raíz. Sin compilación.

## Revisión local
Ejecutar `python3 -m http.server 8000` y abrir http://localhost:8000.
